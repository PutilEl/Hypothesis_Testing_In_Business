# 🔍 **Проект «Проверка гипотез в бизнесе»**

Компания крупного сервиса проката самокатов GoFast предоставила три датасета 
с данными о пользователях сервиса, их поездках за один год, а также стоимости 
услуг в подписках. Необходимо проанализировать демографию пользователей и 
особенности использования самокатов, а также определить возможную выгоду от 
распространения платной подписки на самокаты.

🎯 **Цель проекта** - на основе предоставленных данных проанализировать 
поведение пользователей сервиса проката самокатов GoFast, выявить ключевые 
демографические и поведенческие паттерны, а затем с помощью статистических 
методов оценить, насколько выгодно для компании внедрять или масштабировать 
платную подписку.

📋 **Задачи проекта:**
1. Загрузить данные и ознакомиться с ними;
2. Выполнить предобработку данных;
3. Провести исследовательский анализ данных;
4. Объединить данные;
5. Подсчитать выручку;
6. Проверить гипотезы;
7. Смоделировать распределения.

### 📚 **Источники информации**

В данном проекте использованы базы данных (БД): 

- /datasets/users_go.csv - содержит информацию о пользователях сервиса;
- /datasets/rides_go.csv - содержит информацию о поездках;
- /datasets/subscriptions_go.csv - содержит информацию о подписках.

### 🛠️ **Инструменты и технологии**
- Среда разработки: Jupyter Notebook;
- Язык программирования: Python;
- Основные библиотеки: pandas, matplotlib, scipy.

### 🏆 **Результаты**

- **Аудитория:** основная — молодые люди 20–30 лет; распределение по городам 
равномерное, доля несовершеннолетних — 5 %;
- **Поведение:** средняя поездка — 18 минут, 90 % поездок короче 4502 м, 
вероятность поездки дольше 30 минут — всего 2 %;
- **Эффект подписки:** подписчики катаются дольше (19 минут против 17) и 
приносят больше выручки (359 руб. против 322 руб.), разница статистически значима;
- **Дистанция:** подписка не увеличивает длину поездок (нет оснований 
считать, что средняя дистанция больше 3130 м).

### 💡 **Рекомендации**

- **Продвигать подписку:** она повышает выручку и вовлечённость — стоит сделать 
её привлекательнее (бонусы, гибкие тарифы);
- **Таргетировать молодёжь:** фокусироваться на аудитории 20–30 лет в 
маркетинговых кампаниях;
- **Оптимизировать логистику:** учитывать типичную длительность (до 22 минут) и 
дистанцию (до 4502 м) при размещении станций и планировании зарядки самокатов;
- **Не делать упор на дальние поездки в рекламе подписки:** она не влияет на 
длину маршрута.
